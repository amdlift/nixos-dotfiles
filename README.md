# nixos-dotfiles

[![Nix flake check](https://github.com/amdlift/nixos-dotfiles/actions/workflows/test.yml/badge.svg)](https://github.com/amdlift/nixos-dotfiles/actions/workflows/test.yml)

NixOS configuration for my machines, built on [den](https://den.denful.dev) +
[flake-parts](https://flake.parts) with a [dendritic](https://github.com/mightyiam/dendritic)
layout — every file under `modules/` is auto-imported by
[import-tree](https://github.com/vic/import-tree), and `flake.nix` is generated by
[flake-file](https://github.com/vic/flake-file).

## Hosts

| Host      | Role    | Highlights                                                              |
| --------- | ------- | ----------------------------------------------------------------------- |
| `legion5` | desktop | Mango (Wayland), ly, Stylix/gruvbox, NVIDIA PRIME offload, Steam, printing |
| `danya`   | server  | Home Assistant, Immich, Nixarr, ZFS, Matter/Thread, Podman                |

Both run `x86_64-linux` with the `aaron` user and home-manager.

## Usage

Host build targets are exposed as flake packages via [nh](https://github.com/nix-community/nh):

```console
# build only (default action)
nix run .#legion5

# any other nh action
nix run .#legion5 -- switch
nix run .#danya -- switch
```

Check and format:

```console
nix flake check
nix fmt
```

Update inputs:

```console
nix flake update
```

After editing `flake-file.inputs` in any module, regenerate the flake:

```console
nix run .#write-flake
```

## Layout

```
modules/
  hosts.nix              # declares hosts, roles and their users
  defaults.nix           # stateVersion, flakes, home-manager defaults
  dendritic.nix          # core inputs + dendritic wiring
  *.nix                  # reusable aspects (stylix, podman, nvidia, ssh, ...)
  hosts/<host>/          # per-host aspects + hardware config
  users/<user>/          # per-user aspects (home-manager)
secrets/                 # agenix-encrypted secrets
wallpapers/
```

Shared aspects live at the top level of `modules/` and are pulled in by a host's
`includes`. Anything specific to one machine goes under `modules/hosts/<host>/`.

## Secrets

Secrets are managed with [agenix](https://github.com/ryantm/agenix) and keyed to
each host's SSH host key (see `secrets/secrets.nix`).

```console
cd secrets
agenix -e hass-secrets.age
agenix -r              # rekey after adding a host
```
